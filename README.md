# Кабинет здоровья доктора Горшечникова

Одностраничный сайт кабинета здоровья (Салават, ул. Юлаева, 29а, Дом Быта, 3 этаж).

Статический сайт без сборки: `index.html`, `assets/css/style.css`, `assets/js/main.js`, изображения в `assets/img/`.

## Локальный запуск
```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Деплой на Vercel
Импортировать репозиторий в Vercel → Framework Preset: **Other**, Build Command пустая, Output Directory — корень (`.`).

## Что стоит подтвердить у клиники
- Акция «Консультация и процедура — бесплатно» (для новых пациентов) — по просьбе клиента.
- Форма записи открывает WhatsApp на номер +7 993 044-06-19 — проверить, что на номере есть WhatsApp.
- Часы работы на сайте не указаны.
- Фото команды пока старые — заменить, когда будут в хорошем качестве.

## SEO
Основной адрес — `https://www.drgorshechnikov.ru` (с www; адрес без www перенаправляется на него настройками домена в Vercel — не добавлять обратный редирект в `vercel.json`, будет петля). Домен прописан в: `index.html` (canonical, og:url, og:image, twitter:image, JSON-LD), `robots.txt`, `sitemap.xml`.
- При правке контента обновить `<lastmod>` в `sitemap.xml`.
- Описания процедур для окна «Подробнее» лежат в HTML карточек (`.dir-card__info`), а не в JS — так их видят поисковики.
- Вопросы FAQ продублированы в JSON-LD (`FAQPage`) — при изменении вопросов править оба места.
- Аватары в первом экране — миниатюры `assets/img/*-thumb.webp` (96×96).

## Дизайн и откат
Спокойный вид без «шаблонных» эффектов: белый фон, один фирменный цвет (индиго логотипа `#5952fb`), шрифт Manrope. Все стили — в `assets/css/style.css`.
Намеренно убрано и не стоит возвращать: заставка при загрузке, светящиеся пятна и сетка на фоне, «парящие» карточки вокруг фото, градиенты и блик на кнопках, «магнитные» кнопки, параллакс, появление блоков при прокрутке, пульсации, бегущая строка, номера разделов 01–06, подписи капсом над заголовками, слова-акценты курсивом.
- Версия до чистки: ветка `backup-before-cleanup` (или Instant Rollback в Vercel).
- Старый дизайн золото/тёмно-синий: ветка `backup-gold-navy`.
Логотип GA: `assets/logo-ga.svg` (на странице — один `<symbol id="ga">`), фавикон: `assets/favicon.svg`.
